Helios now runs on macOS and Linux as well as Windows.

## Downloads

- `Helios-windows.zip`: Windows 10 and 11, 64-bit. Unzip and run `Helios.exe`.
- `Helios-macos.zip`: macOS 14 or newer on Apple Silicon (M1 and later). Intel Macs are not supported yet.
- `Helios-linux.tar.gz`: Linux x86_64, Ubuntu 22.04 or newer (or a system of the same age). Extract and run `Helios/Helios`.

None of the builds are signed. Windows may show a SmartScreen warning (More info, then Run anyway). On macOS, open the app the first time with right-click, then Open, or allow it under System Settings, Privacy & Security. On Debian and Ubuntu you may need `sudo apt install libxcb-cursor0`. The README has the details for each system.

Your data stays where it was on Windows (`%APPDATA%\Helios`). On macOS it is in `~/Library/Application Support/Helios`, on Linux in `~/.local/share/Helios`.

## Changes

- New macOS app (`Helios.app`) and Linux build, made and checked by the release workflow.
- Opening a project folder from Helios now works on macOS and Linux. It used to work only on Windows.
- On Linux, Helios stopped noticing outside changes to its data file after its own first save. Fixed.
- When running from source on Python 3.10 or 3.11, PySide6 6.12.0 could crash Helios after a while of use. That version is now excluded for those Pythons. Python 3.12 and newer, and the downloads above, were not affected.
- New `build_app.sh` to build Helios yourself on macOS or Linux, next to `build_exe.bat` for Windows.
- Tests now also run on macOS.
